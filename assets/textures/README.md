# 🎨 GameOfTex - Ultra Çözünürlüklü Doku ve Görsel Rehberi

Bu klasör, oyun içindeki donanımlara gerçekçi ve ultra yüksek kaliteli (2K/4K) görseller giydirmenizi sağlar!

Oyun bu klasörü otomatik olarak tarar. Eğer aşağıdaki isimlerde PNG resimleri koyarsanız, procedürel çizim yerine doğrudan sizin koyduğunuz resimleri çizer:

### 📁 Desteklenen Görsel Dosyaları:
1. **`gpu_card.png`**:
   * **Açıklama:** Ekran kartının gövdesi / ön yüzü.
   * **Önerilen Format:** Şeffaf (transparent) PNG. Dikdörtgen dikey oran (yaklaşık 1:2.4, örn. 500x1200 px).
2. **`fan_blade.png`**:
   * **Açıklama:** Dönen fan pervanesi.
   * **Önerilen Format:** Şeffaf PNG, kare (örn. 512x512 px). Ortası merkezli fan kanatları. Oyun bu pervaneyi GPU ısısına göre otomatik döndürür!
3. **`warehouse_bg.png`**:
   * **Açıklama:** Depo / Madencilik tesisi arka plan görseli.
   * **Önerilen Format:** Yüksek çözünürlüklü 1920x1080 veya 4K JPG/PNG.

> **Not:** Eğer henüz görsel eklemediyseniz endişelenmeyin! Oyun otomatik olarak kendi yüksek kaliteli 2D çizim motorunu kullanacaktır.
